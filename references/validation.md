# 模型检验、对比与缺失处理

## 检验回答不同问题

| 内容 | 它支持什么 | 不能据此声称什么 |
|---|---|---|
| 单位、范围、约束残差核查 | 实现或结果满足已核对的关系 | 模型对现实完全正确 |
| 解析解/已知特例对照 | 该特例下正确性 | 所有场景准确 |
| 网格/步长收敛 | 离散分辨率的影响 | 物理参数不确定性已解决 |
| 独立测试或回测 | 相应评价分布与信息条件下的表现 | 无条件泛化 |
| 模型/算法对比 | 公平条件下的相对表现 | 不公平设置下的普遍优越 |
| 参数敏感性 | 参数在研究范围内的影响 | 数据扰动下固定方案必然可靠 |
| 固定方案扰动测试 | 执行既定方案对扰动的承受能力 | 可适应性重优化的表现 |
| 扰动后重优化 | 允许重新决策时的响应 | 原方案无需改变即可保持性能 |

**最低要求是每个核心结论有与其强度相称的证据，并非每问必须完成全部检验。** 如果题目明确要求检测误差分析、可靠性或某种对比，缺失就是答案未完成，不能标为“不适用”。

## 模型对比缺失时

1. 先查结果、日志、历史配置里是否已有对照，不以文件名判定。
2. 同一模型不同求解器与不同模型的比较分别命名。
3. 没有对照时报告当前结果、已有检验和局限，删除“较其他模型更优”等表述。
4. 若用户希望且已授权补充，选择最能回答问题的简单基准，复用同一数据划分、信息结构与评价口径；记录新增实验后再写比较。

## 敏感性缺失时

不自动套用 ±5%、±10% 的参数列表。先问哪个结论依赖哪个不确定参数，参数范围能否由题意、测量误差或场景给出。实际补做时记录基准、取值范围、固定/重优化、随机重复、目标变化、关键决策变化及可行性。

弹性形式 $S=(\Delta Y/Y_0)/(\Delta X/X_0)$ 仅在基值非零且该解释合理时使用；近零基值或不连续决策考虑绝对差、有限差分、阈值/切换点。不要用均值掩盖单个关键参数或极端情景下的大变化。

## 允许的轻量复核

写作时可以从现有结果算总和、比例、范围、残差和表间一致性；可以核对方案是否满足已有约束。它们是新增核查事实，应保存计算依据，不改称新增模型对比或敏感性实验。

## 缺口分析的交付位置

独立交付 `论文完善建议.md`，按 [建议文档规则](revision-advice.md) 给出“缺少什么 → 影响哪个结论 → 目前可以怎样表述 → 若补做需要什么输入与计算”，并区分关键待核查、优先完善与可选美化。流程图、数据侧写图和逐问结果图的建议也放在该文档，明确来源、位置及作者选择。

论文不设“缺失项说明”，模型评价只保留简洁的优点和缺点；不能把图表不够美观当作模型缺点。未做的可选分析或尚未采纳的配图建议不阻断全文交付。关键结果无来源或赛题必答项缺失时保持草稿状态，正文结论不超出已有证据。不要通过反复询问延误可完成部分。
