# 题型分流：字母作索引，数学任务决定写法

本地资料已经说明字母不足以决定结构：A092/A127/A165/A175 是定日镜机理计算与设计优化；B226 是测线几何与布设优化，B060/B157 是光学参数反演；C050/C228 是销售分析、预测与经营决策，C023/C132 是统计推断、分组优化与异常识别。006109B 又是车辆路径与调度。因此不要建立“A 只写物理、B 只写优化、C 只写机器学习”的硬规则。

## 根据每问要输出什么选择

| 实际任务 | 主模块 | 最关键的内容 | 适合的已有验证 |
|---|---|---|---|
| 推导几何关系、运动/能量规律 | 机理 | 坐标、机理、量纲、适用域 | 极限情况、解析关系、守恒 |
| 由观测估计物理参数 | 机理＋统计 | 正问题、反问题、噪声与可辨识性 | 残差、独立观测一致性、参数不确定性 |
| 资源、路径、选址、调度决策 | 优化 | 变量、目标、约束、可行解与求解状态 | 可行性、上下界、公平基准 |
| 相关关系、回归、组间差异 | 统计 | 样本单位、关系式、估计与检验条件 | 残差、效应量、置信区间 |
| 预测或分类 | 数据 | 输入信息时点、划分、训练、评价 | 同一测试集上的误差、校准或分类表现 |
| 聚类、分组、评级、排序 | 数据＋可能的优化 | 距离/尺度、目标、边界及决策解释 | 稳定性、覆盖性、权重敏感性 |
| 预测后做运营决策 | 数据＋优化 | 预测输出到决策输入的完整映射 | 预测误差对成本、可行性、决策的影响 |
| 提出数据需求或建议 | 论证 | 缺失信息如何影响目标；可采集指标与用途 | 现有证据、明确适用边界；不硬造数值 |

一份论文只维护一套术语、符号与视觉风格；模块按问切换。共享模型给出一次完整定义，后续说明新增变量、目标或约束，并提供更新后的模型或明确的引用式组合。

## 章节分配

主要篇幅给决定答案的建模和结果解释。预处理仅保留影响结论的操作；没有数据处理的机理题不设“缺失值分析”；没有训练阶段的优化题不设“训练集”；统计题不为了统一模板而硬写优化目标。

建模与求解应能够区分，但小问较短时不必拆成大量三级标题。各问小结只在需要明确答案或承接接口时使用，避免重复摘要和结果段。
