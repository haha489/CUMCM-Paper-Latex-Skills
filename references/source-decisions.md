# 资料采纳与改写说明

## 用户原规范

保留 `数模论文写作_SKILL.md`、`数学建模论文标准写作规范与模板.md`、`微网论文摘要提炼与复用指南.md` 中：按任务分模块、只写实际工作、数据处理解释原因、目标与约束分别解释后给完整模型、总—分摘要、关键数字、图下表上、结果必须解读、矛盾必须核查。

调整：固定流程改为按实际任务选择；“预测必须有比较”“敏感性至少一种”“摘要结果必须有基准”等表述改为证据充分性判断。比较/敏感性若是原题要求，仍属于必答项；否则缺失不阻断可完成的写作。删除泛泛的求解器机理、统计结论和可复制旧数字，避免由示例误变成当前事实。

按用户后续偏好，末尾综合模型评价仅保留优点和简短缺点；一般的详细改进设想与缺失项分析改为独立的作者建议文档。强化总体流程、开篇数据侧写和逐问结果图的盘点，建议交代具体数据、位置与阅读价值，由作者选择。原题要求的改进任务仍在对应问题正文回答。

## Word 模板

保留其逐问模型与结果组织、分析与总体思路位置。已从旧 `.doc` 的可读内容确认含物流货量字段与 AxMath 公式对象，这些不进入通用模板。当前环境无法通过 Word COM 读取全部样式，因此没有宣称逐像素复刻 Word；以已核实比赛格式和可读性重新实现 LaTeX 排版。

## 开源压缩包

来源：用户提供的 `cumcm-paper-hand-skill-main.zip`，其中 README 标注项目 [Mr-potato-123/cumcm-paper-hand-skill](https://github.com/Mr-potato-123/cumcm-paper-hand-skill)。本次以本地 ZIP 内容为准，不宣称审查了远端最新版。

采纳：成果盘点、从已有建模材料撰写、子问间的真实承接、按需选 1–2 篇、OCR 只供定位、交付可编译源工程。

不采纳：

- 过宽触发词将写作 skill 变为完整建模技能。
- A/B/C 固定题型、固定假设数和文献数。
- 已有成果仍强制补笔记、所有缺失都先询问、Markdown 必须确认后才写 LaTeX。
- 固定三问和目录、不区分当前赛题规则、姓名默认进入论文首页。
- 图像不存在时静默跳过、虚构参考文献占位、所有算法均返回“最优解”。
- “LaTeX 编译零错误”直接等同于论文质量合格。

工程与脚本重新编写；只保留 5 篇已有 OCR 文本作为检索辅助，包含其来源提示，并随附 [上游 MIT 许可证](../LICENSE.upstream)。原论文属于原作者，MIT 项目许可不能自动视为对第三方论文的再授权；论文库用于用户提供材料的本地写作参考。
