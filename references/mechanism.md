# 机理、几何、仿真与反演

## 正问题的论证顺序

现实对象与必要简化 → 坐标/状态/单位 → 几何或守恒关系 → 完整方程及初始/边界条件 → 参数来源 → 数值方法 → 结果及误差。

- 坐标图标出原点、轴向、角度正向及关键距离；转换矩阵说明方向，角度单位与代码一致。
- 物理量区分瞬时值、累计量与时间平均值。功率积分为能量必须带时间步长；平均效率的加权口径不能靠文字推测。
- 经验公式说明来源、单位约定与适用范围；不能直接照抄 PDF 中丢失的上标或 OCR 的符号。
- 数值离散说明步长、网格、积分/插值方法、误差容限及事件判定方式。网格扫描找到的最大值只是在相应搜索域和分辨率下取得的结果。
- 程序若使用近似几何或简化边界，正文必须保留这一近似，讨论它对结论的影响。

## 反问题

先写可观测量如何由待估参数生成，再写目标残差、权重、参数范围、初值与求解法。多个物理参数可能互相补偿：曲线拟合很好不代表每个参数都被唯一确定。共享参数的联合拟合需说明哪些观测共同约束它，哪些参数分组估计。

适合呈现：观测与拟合曲线、残差结构、参数估计与单位、不同测量条件的一致性。没有真值时报告拟合残差与交叉一致性，不把它们称作真实测量误差已知。

## 验证与措辞

先看实际已有证据：量纲、范围、守恒、对称性、退化情况、解析解对照、步长/网格收敛、重复模拟误差。选择与问题风险最相关的内容，不预设必须做齐。

两个算法结果接近只能支持数值一致性；不能单独证明物理模型正确。步长变化检验的是离散误差，物理参数变化检验的是参数敏感性，两者名称与解释分开。没有独立观测验证时，限定在给定机理假设与参数范围内讨论。
