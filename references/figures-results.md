# 图表与结果解释

## 选图而非堆图

先给每张拟用图写一句“它要支持什么结论”。没有明确论点或与表格重复的图可以不放。优先保留：关键数据规律、模型结构/几何关系、最终方案、主要误差和有结论的比较。

统计图和科研曲线来自真实数据、代码或已有结果。需要修改配色、字体、轴或分面时尽量从源数据重绘，并保持数值含义。概念示意图必须与结果图区分，不能用生成图替代测量或计算结果。

## 开篇的数据侧写与总体流程

数据侧写用于让读者看见影响建模选择的特征，通常置于共享数据章节，或首个涉及该数据的问题之前。结合现有数据优先选少量信息密度高的图；表中列的是候选，不要求全部绘制。

| 需要解释的数据特征 | 合适的图 | 与后文的连接 |
|---|---|---|
| 取值范围、偏态、极端值与组间差异 | 直方图、箱线图或分组分布图 | 说明变换、误差结构或分组依据 |
| 趋势、周期、峰谷与时间覆盖 | 时序折线、按时段聚合图或时间热图 | 说明预测时域与调度难点 |
| 变量关系、非线性与组内差异 | 散点图、分组散点或有针对性的相关热图 | 支持模型结构选择；相关性不解释成因果 |
| 样本组成、重复观测或缺失分布 | 类别计数、个体记录数分布或缺失率图 | 说明分析单位、样本不平衡及处理依据 |
| 空间布局或物理观测特征 | 节点/地形图、实测曲线或带坐标的几何示意 | 解释空间约束、机理参数与观测条件 |

涉及预测时，只用合适的训练或探索数据作出模型选择，避免看过测试结果后调整方案。没有缺失值时不为凑图生成全零缺失率图；纯机理题可以用几何/观测示意替代统计侧写。

总体流程图通常放在“问题分析”末尾，明确原始输入、共享处理、各问模型和主要输出。箭头表示真实数据或逻辑依赖，各问独立时并列显示；待完成的分析不画成已执行环节。只有单问流程较复杂、总体图无法解释时才另建议算法流程图。

## 每问结果优先配图

逐问检查是否有直观呈现核心答案的主图，优先一张主图或组合图，必要的精确数值表仍保留。图形应对应“算出了什么、方案是什么、主要规律是什么”，不能只放算法流程图就算完成结果配图。

| 结果类型 | 优先考虑的主图 |
|---|---|
| 物理量、仿真与参数反演 | 状态/响应曲线、场分布、观测与拟合及残差组合图 |
| 优化、路径与调度 | 路径图、甘特图、资源分配热图或成本构成图 |
| 预测与回归 | 观测—预测曲线、观测—预测散点或误差分布；标清训练/测试区间 |
| 分类 | 混淆矩阵、已有的 PR/ROC 曲线或校准图；标清类和阈值 |
| 分组、排名与决策 | 分组边界与指标、分组结果分布或排序点图 |
| 理论推导、判据或建议 | 有助于理解的几何/判定示意；仅有单值或简短结论时可用表与文字 |

先利用已有合适图表。发现缺图、缺少绘图数据或更优呈现方式时，将建议写入 [论文完善建议](revision-advice.md)，说明实际需要的字段、坐标、分组、单位和拟放位置。未获作者采纳的可选新图保留为建议，已授权的绘图按现有数据制作并更新状态。不为“每问一图”强造曲线、误差带、基准或虚假样本；不适合配图的问在建议文档解释理由，不在论文里添加无图说明。

## 排版

- 图题在下，表题在上；先 `\caption` 后 `\label`，正文用 `\ref` 或 `\eqref`，不手敲编号。
- 图轴给变量与单位，图例能区分方案；量级、对数轴、归一化及误差带定义写清。不同方案对比尽量统一尺度。
- 矢量图优先 PDF；栅格图按最终显示尺寸保证文字清晰。LaTeX 避免直接依赖 SVG 转换和 shell-escape。
- 表格使用三线表；小数位与精度一致，符号和单位统一。不把“0.000”写成零误差，必要时用科学记数或检测限表述。
- 多子图共同支持一个论点时组合，子图标记与图题对应；不要把大量小图挤到文字无法辨认。
- 浮动优先 `[htbp]`，仅有必要时固定位置；长表用 `longtable`，不要整体缩小成不可读的表。
- 重要图紧邻首次讨论处。页面空白、图表跨节漂移、表题与表分离都需检查。

## 数字与比较

下降率在正基准成本 $C_0$ 下为 $(C_0-C_1)/C_0$；表达为百分数时乘以 $100\%$。基准为零或含负值时，优先报告绝对差并解释口径，不滥用“提升百分比”。多次实验说明重复次数和汇总方式；不要只选最好的随机种子。

表中只有在同一任务、同一评价条件下才标“最好”。置信区间、标准差和极值不可混称误差范围。可行率、最优性 Gap 与预测误差不能在一列混排。

## 解读

图表之后说明最重要的趋势、与任务的关系以及可支持的解释。用具体证据连接模型机制；无法验证的原因只作为解释假说。无需把所有单元格再复述一遍。

LaTeX 已引用但文件缺失的图片属于构建错误，必须修复；尚未设计/采纳的候选图属于完善建议，不能先放空图引用。技术记录可指出具体文件，正文不保留编辑提示。表格最好从核定结果生成；摘要与正文重复数字通过 `\Result{...}` 统一。
