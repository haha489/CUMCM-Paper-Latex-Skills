# 正文：让方法服务于答案

## 组织方式

通常从标题与摘要进入，随后是问题重述/引言、问题分析、必要假设、常用符号、各问的模型与求解、模型评价、文献和附录。公共数据处理较多时单独成章，否则留在对应小问。章节数量由内容决定，不机械套目录；比赛格式对目录页另有要求时优先执行。

先写每问最重要的答案与证据位置，再向前补其模型解释，最后写摘要。写作阶段可直接维护 LaTeX，不必先生成一份全文 Markdown 等待确认。

## 各部分应承担什么

| 部分 | 写什么 | 避免什么 |
|---|---|---|
| 标题 | 对象、任务、核心机制或方法 | 连续堆算法名，夸大创新 |
| 重述/引言 | 压缩背景，准确列出每问要求 | 长篇复述赛题、编造行业统计 |
| 问题分析 | 难点、为何采用现有方法、问题间关系 | 提前抄一遍模型公式与求解过程 |
| 假设 | 实际采用的必要简化、依据和影响 | 固定凑 5–10 条，假设预测完全准确 |
| 符号表 | 高频符号、含义、单位或定义域 | 列每个临时变量、同符号多义 |
| 模型 | 对现实关系的数学刻画与关键推导 | 公式拼贴、无解释的通用模型 |
| 求解 | 实际算法与对结果有影响的细节 | 程序逐行翻译、虚构求解器机制 |
| 结果 | 直接答案、证据、规律及解释 | 全文只引用附件、不展示结论 |
| 模型评价 | 仅“模型优点”和“模型缺点”；优点有依据，缺点简短具体 | 扩写改进/推广小节、照搬待办清单、空泛自夸 |

假设中区分题目已给条件、建模简化与参数估计。不要把赛题事实重写成假设。符号首次出现时就定义，不强迫读者来回找符号表。

## 模型评价：仅写优点和缺点

章节标题统一为“模型评价”，下设“模型优点”“模型缺点”。这项约定针对论文末尾的综合评价，不删去各问中确实完成的误差检验、模型比较或敏感性分析。

若原题明确要求改进模型、推广方案或提出建议，它们仍是必答内容，应在对应问题章节完整回答，不移出正文。

- **模型优点**：挑最有价值的实际贡献，说明方法特点如何支持题目目标。可涉及机制清晰、约束完整、信息利用或求解效率，但性能结论需有对应证据。
- **模型缺点**：篇幅明显少于优点，通常 1–2 条、每条一两句；优先说明真实的局部近似、扩展到其他场景的适配成本或非关键表达能力限制。只在本项目确实存在时使用这些角度，不直接套用“未考虑现实因素”“计算量大”。无需为达到条数编造不足。
- **不另设“模型改进”“模型推广”“缺失项说明”小节**。详细问题诊断、补充实验、改图计划与扩展设想写入独立的 `论文完善建议.md`。
- 缺少流程图、图不美观、章节不均衡属于写作建议，不冒充模型缺点。关键结果错误、题目必答项缺失或模型适用条件则不能通过选写次要缺点而掩盖；在建议文档说明具体影响，相关正文结论保持必要限定。

正文只保留供评阅人理解研究所需的内容，不出现“此处建议补图”“作者自行确认”“缺失项如下”等编辑说明。草稿状态及未完成工作的交代放在交付说明和独立文档中。

## 段落的论证密度

每个关键段落最好完成一个任务：提出可判断的结论，用公式/图表/计算支撑，解释其机制或边界。例如先指出峰值时段导致容量约束紧，再用具体时段与资源量支持，最后解释调度如何应对。没有直接证据的机制解释使用“可能与……有关”等限定，不写成被实验确认。

保留对理解方法有用的算法参数、容差、信息时点和单位；文件写盘、函数报错、工具调用过程放复现记录。正文的数据来源可用“附件 2 的销售流水”等可读名称，附录再列文件映射。

术语要准确：比较的是同一模型的求解算法，还是不同模型；灵敏度分析、数值收敛、数据扰动、信息价值分别是什么。方法名与软件库名不能混用。

## 数学表达

- 先说明公式的作用，再给公式，接着解释新符号与适用域。必要的推导保留，常规代数压缩。
- 使用 `equation`、`align` 或 `aligned`；只有后文引用或关键模型式才需编号。
- 下标范围、随机/确定变量、向量维度统一。单位用正体，变量用数学斜体；文本中的百分比正确转义。
- 一个计算步骤的正确性不等于整个模型的有效性。不要用“由此证明模型合理”作为每问固定结尾。

## 文献与附录

引用实际使用的理论、方法、数据来源和领域依据，不规定篇数。核实题名、作者、年份和出版信息；优先原始论文、官方文档或专著。公开来源可在线核查，已提供全文也可据原文确认；不能访问的字段不要编造。

只把真正引用的文献列入文末。参考论文的文献表是检索线索，不能整段搬入。写作范例通常不需要作为当前模型理论依据引用。

附录按比赛要求包含必要推导、完整程序和支撑材料清单，并与正文一致。若比赛要求完整代码，不以“核心代码片段”替代；界面软件的命令/操作记录按要求说明。长代码单独分页排版，不能挤占核心论证。
