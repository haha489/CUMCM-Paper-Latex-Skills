# 交付核查：先真实性，再论证，最后版式

在 `写作核查.md` 记录“通过 / 未通过 / 不适用”及证据，不给一个没有依据的总分。

## 1. 核心答案

- 逐项覆盖原题要求，包括小问内嵌要求、指定时点、误差分析和输出表。
- 关键结果有来源，摘要—正文—图表口径一致；换算、比例、有效数字正确。
- 实际执行的方法与正文公式相符；新旧运行结果没有混用。
- 未确认冲突、题目必答项缺失或无来源的核心数字意味着尚未成稿。

## 2. 数学与论证

- 输入、符号、单位、初边值、变量取值域和约束索引完整。
- 读者能从论文理解计算逻辑、最终答案和主要限制。
- 无训练/测试信息泄漏的隐瞒；拟合、预测、因果、最优性等用词与证据相符。
- 对比公平，敏感性、鲁棒性与数值收敛名称正确。没做的可选分析可以省略，不能伪造。
- 没有照搬参考论文的行业数字、结果、理论复杂度、文献或结论。

## 3. 结构与语言

- 模型选择有题意/机制依据，关键公式有解释；各问关系真实且清楚。
- 摘要精炼且完整，重要答案不藏在附录；共享处理不反复写。
- 每张关键图表有论点与正文解读，单位、图例、精度清楚。
- 最后的“模型评价”仅设“模型优点”和“模型缺点”；缺点明显短于优点，通常一至两点真实、局部的不足，不为凑数虚构。不额外设置改进、推广或缺失项说明。
- 无夸大效果、凑工作量或研究过程元话语；必要的结论限定位于对应模型或结果处。
- 已盘点总体流程、开篇数据侧写与每问核心结果的配图；已有图能解释结论，未采纳的建议或不适合配图的理由写入独立建议文档，不在正文留空图或待办。

## 4. LaTeX 与 PDF

- 使用新编译结果，无缺图、未定义引用、重复标签、缺字或阻断错误。
- 摘要/正文页数和格式符合适用比赛；不能靠调小字号规避要求。
- 逐页查看最终 PDF，无公式出界、标题孤悬、大段不合理留白、图表错位、不可读代码。
- 文献真实且实际被引用；不存在空文献、占位内容或草稿提示。
- 匿名要求同时检查正文、图像、附录、文件清单及 PDF 元数据。自动搜索只能辅助，不能替代检查。

## 5. 可复现与交付

- 源工程在相对路径下包含必要图片、章节、文献与样式；关键结果有统一显示来源。
- 完整代码与支撑材料依比赛规定提供；用户成果原件保留。
- 记录编译命令、实际执行的检查、新增计算及未解决问题；证据记录不自动并入正式正文。
- 单独交付 `论文完善建议.md`，建议对应实际稿件，包含优先级、数据来源、放置位置、阅读收益及作者选择；可选美化与关键缺口分开。作者尚未决定的可选建议不阻断论文交付。
- 报告具体状态：已完成并编译 / 已编译草稿 / 源文件已完成但未编译。检查脚本退出成功不能代替对论文质量的判断。
