基于 LogisticGAM 的 NIPT 的时点选择与胎儿的异常判定 
摘  要 
无创产前检测通过分析孕妇血浆中胎儿游离 DNA 评估染色体异常，其准确性受孕
周、孕妇 BMI 及个体差异影响。本研究基于大量样本，提出合理分组与时点优化策略，
以提高检测准确率、缩短治疗窗口并降低漏诊误诊风险。 
针对问题一，我们首先对于数据中的缺失值，异常值及部分变量进行数据预处理，
接着进行描述性统计和可视化处理，数据呈现出非线性、近似正态，弱相关性和独立性
的特点，为此我们引入固定和个体随机效应构建 广义加性混合模型（ GAMM）求解得
到边际 R2、条件 R2 和 RMSE 分别为 0.177、0.806 和 0.012，说明个体差异解释大量变
异且模型准确率较高， 通过VIF 共线性检验并与 OLS,LME 模型比较得到无多重共线性
且模型性能优越， 接着我们对于整体， 成组效应， 单个系数分别使用了最大似然比检验，
Wald 检验，t 检验和 z 检验分析显著性得到上述 p 值均小于 0.001，具有极强显著性。 
针对问题二，我们创新性引入 多维聚类-决策树区间映射模型 ，通过无监督多维聚
类利用所有可用特征，并以决策树将簇映射为互不重叠的 BMI 区间，借助 Bootstrap 
稳定性检验与敏感性分析保障分组的可重复性与鲁棒性。 接着利用Y 染色体浓度构造二
分类达标特征将 Logistic 与 GAM 结合构建 LogisticGAM 模型，利用两种最佳 NIPT 时
点准则求解得到 BMI 分组和 NIPT 最佳时点（周）为：[20.70,32.23]-10.94、[32.23,34.1
5]-11.69、[34.15,34.70]-12.37、[34.70,35.95]-13.23、[35.95,46.88]-23.05。 接着分别对于B
MI 分组和 NIPT 最佳时点求解施加多种扰动， 得到平均变化不超过10%， 模型鲁棒性强。
最后通过多模型对比得到 LogisticGAM 模型 AUC=0.66，与其他模型相比速度快，精度
较高的特点。 
针对问题三，我们扩充变量使用多维聚类 -决策树区间映射模型，并从核心变量，
临 床 扩 展 变 量 和 测 序 扩 展 变 量 三 个 维 度 增 加 变 量 构 建 多维广义加性模型
（Multi-LogisticGAM），解得 BMI 分组和 NIPT 最佳时点 （周） 为：[20.70,31.91]-12.21、
[31.91,33.83]-20.83、[33.83,35.55]-20.73、[35.55,36.57]-23.92、[36.57,46.88]-26.34。接着
从更多维度施加扰动，NIPT 最佳时点表现稳健，BMI 分组对数据变化略为明显。最后
多模型对比显示模型为 AUC=0.88，较问题二和其他模型优势明显。 
针对问题四，首先利用散点图分析不同变量间的关系，接着从染色体信号，测序质
量和个体差异三个维度构建特征，建立单染色体 Logit 模型，同多模型比较下表现最优
模型 AUC 和准确率分别为 0.689 和 73.61%，最后我们针对不同的实际情况给出 GC 和
Z 值赋权判别法，OOF 阈值法，决策树判别法，以便灵活使用。 
关键词：多维聚类-决策树区间映射模型；LogisticGAM 模型；单染色体 Logit 模型

一、 问题重述 
1.1 问题背景 
无创产前检测（NIPT）是通过采集孕妇血液、检测胎儿游离 DNA 片段，来判定早
期胎儿是否存在 21 号（唐氏综合征）、18 号（爱德华氏综合征）或 13 号（帕陶氏综合
征）染色体异常，以明确胎儿健康状况。其准确性的核心取决于胎儿性染色体浓度（男
胎 Y 染色体浓度需达到或高于 4%， 女胎X 染色体浓度需无异常）和检测时点的风险等
级（12 周以内（早期）发现异常的干预风险较低，13-27 周（中期）风险较高，28 周以
后（晚期）风险极高 ）。因此，做到“尽早检测”与“结果准确”的平衡是 成功应用
NIPT 的关键。 
同时实践表明男胎 Y 染色体浓度与孕妇孕周数、 身体质量指数 （BMI） 等紧密相关。
但由于忽略了孕妇年龄、孕情等个体差异，一般的根据 BMI 简单分组并设定统一检测
时点的方法准确性不高，还可能因时点不当导致测序失败或缩短治疗窗口期， 增加潜在
风险。 因此为了尽可能减少检测风险并提高准确度，有必要建立合适的模型分析胎儿染
色体浓度与相关指标的关系、优化男胎孕妇 BMI 分组及最佳检测时点，并探索女胎染
色体异常的判定方法，提升检测可靠性。 
1.2 问题要求 
附件所给出的是大多为高 BMI 孕妇的 NIPT 数据，包含孕妇年龄、BMI、身高、体
重、孕周、检测时间、抽血次数、原始测序总读段数、比对比例、不同特殊染色体的 Z
值、浓度及 GC 含量、染色体非整倍体判定结果等信息。为探究 NIPT 的最佳时点选择
与胎儿异常判定方法，现需结合实际情况与上述数据建立数学模型分析以下问题： 
问题一：建立合适的关系模型，分析男胎 Y 染色体浓度与孕妇孕周数和 BMI 等指
标的相关特性，并检验该模型的显著性。 
问题二：鉴于男胎孕妇的 BMI 是影响胎儿 Y 染色体浓度达标时间（浓度≥4%的最
早时间）的主要因素，要求对男胎孕妇的 BMI 进行合理分组并给出每组的 BMI 区间和
最佳 NIPT 时点以最小化孕妇潜在风险，分析检测误差对结果的影响。 
问题三： 综合考虑身高、 体重、 年龄等多因素、 检测误差及胎儿Y 染色体浓度达标
比例（浓度≥4%的比例），依据男胎孕妇的 BMI 重新进行合理分组并给出每组的最佳
NIPT 时点以最小化潜在风险，分析检测误差对结果的影响。 
问题四：由于孕妇和女胎均不携带 Y 染色体，要求以女胎孕妇的 13 号、18 号、21
号染色体非整倍体判定结果为依据， 综合考虑X 染色体及上述染色体的 Z 值、GC 含量、
读段数及相关比例、BMI 等因素给出女胎异常的合理判定方法。

五、 数据预处理 
5.1 时间格式统一 
⚫ 附件数据中次月经时间与检测日期分别出现“2023/2/1”和“20230531”两种格
式，且男胎数据中的末次月经时间还额外存在“ 2022-12-19”的格式差异，为
消除格式不一致对后续分析的干扰，我们将所有时间记录统一转换为标准
datetime 格式，为准确计算实际孕周、匹配检测时间与胎儿发育阶段提供可靠
的时间维度基础； 
⚫ 同时，为更好量化分析胎儿 Y 染色体浓度与孕周的关联特性和最佳检测时点的
确定，我们将原“周数+天数”形式记录的检测孕周统一转换为以“ 周数”为
单位的连续量化指标，确保孕周数据的一致性与可比性，为后续建模分析提供
标准化的数据支撑。

5.2.2 变量利用 
由于末次月经时间与检测日期的记录属于日期类型的数据无法作为变量直接用于

但是， 考虑到实际情况，我们对 “检测日期与末次月经时间差” 和 “检测孕周天数”

5.2.3 异常值处理 
在异常数据处理中， 考虑到身高年龄等作为孕妇基础生理指标在孕期短时间内的取
值相对稳定，且有较为明确的生理学合理数值波动范围；而染色体浓度、Z 值、GC 含
量等其他数值统计型变量由于检测操作误差等因素的影响可能会出现异常值， 但其总体
波动应符合正常的统计学规律。因此我们依据不同变量的特性采取差异化处理策略： 
⚫ 年龄和身高异常值处理 
在进行孕妇个体基础信息的一致性检查时发现年龄与身高数据存在异常波动： 其
中， 男胎和女胎数据中共计4 位孕妇在孕期不同检测时间点的年龄记录相差 2 岁， 另有
1 位孕妇的年龄记录相差 8 岁；身高数据方面，有 2 位孕妇孕期不同检测时间点的记录
相差 2.0cm，1 位相差 3.0cm，1 位相差 5.0cm。考虑到年龄与身高作为孕妇稳定的生理
指标，在怀孕期间不应出现此类显著差异，推测该异常为记录误差所致。因此我们对上
述异常数据采用对应孕妇个体数据中的众数替代。 
⚫ GC 含量处理 
题目中提到正常 GC 含量范围为 40%~60%， 但是经检测男胎检测数据异常GC 含量
有 451 条，最大偏离 1.38 个百分点；女胎检测数据异常 GC 含量有 220 条，最大偏离
3.23 个百分点。实际上这几乎占据了全部样本 1/3，且偏离程度较低，我们在此处暂时
不对 GC 含量的异常值进行处理。 
⚫ 其余定量变量处理 
由图 2 和图 3 可以看出重复读段的比例、GC 含量和 X 染色体 Z 值等变量均存在超
出 IQR 阈值范围的异常值， 对于此类异常值， 我们均采用硬阈值裁剪（对于不在阈值范
围内的数值，若小于阈值下界则取下界值，若大于阈值上界则取上界值）的方式进行处
理，保证变量合理性。

8.1.2 BMI 优化分组：多维聚类-决策树区间映射模型 
BMI 分组方式的选择实际上有很多种[5]，本小组对于大量的分组方法进行了实验
和探究但是目前大多数分组方式实际上存在三大问题。（1）分组方式仅依靠 BMI 的特
点而不考虑其他变量， 分组过于简单同时不能体现出不同BMI 人群存在的实质区别 （包
括但不限于单纯采用分位数分组， 对BMI 使用一维 Kmeans 聚类） 主观因素。 （2）BMI
分组依赖主观因素的判断， 构造一些相应的风险函数其弊端在于需要选择合适风险函数
且构造合理的参数同时需要自己对不同的风险状况的影响进行人为赋权。 （加速时间失
效模型（AFT），风险函数+动态规划类）（3）构造连续区间进行回归：此种方案虽然
在一定程度上消除部分主观因素的影响， 且可以根据问题进行相应拟合， 但是对于回归
模型的选择仍然是一个重要挑战， 同时在多变量的情况下回归效果仍待考虑。 为了处理
上述弊端，本文创新性的提出了多维聚类 -决策树区间映射模型，其核心思想是通过无
监督的多维聚类将特征相似的个体汇聚到相同的簇，这充分利用了题目中出 BMI 之外
的其他变量， 但带来一个挑战， 在多维聚类的情况下，BMI 分组区间会出现相互重叠的
现象而我们要构造的是互不相交的 BMI 区间，对于此我们将多维聚类所得到的簇作为
“伪标签”代入决策树模型中，仅依赖 BMI 分裂创造出分裂点进一步将分裂出的区间

def _to_np_aw(s: pd.Series) -> pd.Series: 
    s_str = s.astype(str) 
    has_pct = s_str.str.contains('%', na=False) 
    s_clean = s_str.str.replace('%', '', regex=False) 
    vals = pd.to_numeric(s_clean, errors='coerce') 
    vals.loc[has_pct] = vals.loc[has_pct] / 100.0

def elbow_kmeans_multi(features: np.ndarray, k_min: int = 3, k_max: int = 6) -> Tuple[int, 
List[int], List[float]]: 
    inertias = [] 
    ks = list(range(k_min, k_max + 1)) 
    for k in ks: 
        km = KMeans(n_clusters=k, n_init=20, random_state=42) 
        km.fit(features) 
        inertias.append(float(km.inertia_)) 
    x1, y1 = ks[0], inertias[0] 
    x2, y2 = ks[-1], inertias[-1] 
    best_k = ks[0] 
    best_d = -np.inf 
    for k, y in zip(ks, inertias): 
        num = abs((y2 - y1) * k - (x2 - x1) * y + x2*y1 - y2*x1) 
        den = np.sqrt((y2 - y1)**2 + (x2 - x1)**2) 
        d = num / (den + 1e-12) 
        if d > best_d: 
            best_d = d 
            best_k = k 
    return best_k, ks, inertias

def enforce_min_group_size(df: pd.DataFrame, labels: np.ndarray, min_n: int = 20) ->

        if np.all(sizes >= int(min_n)):

        new_id = min(i_small, j_nei) 
        old_id = max(i_small, j_nei) 
        labels_tmp = labels_curr.copy() 
        labels_tmp[(labels_curr == old_id) | (labels_curr == new_id)] = new_id 
        labels_curr = labels_tmp

def build_bmi_intervals_by_tree(

def evaluate_interval_purity(df: pd.DataFrame, intervals: List[Tuple[float, float]], labels: 
np.ndarray) -> dict: 
    bmi_all = df['bmi'].astype(float).values 
    purities = [] 
    dominant_clusters = [] 
     
    for i, (lo, hi) in enumerate(intervals): 
        if i < len(intervals) - 1: 
            mask = (bmi_all >= lo) & (bmi_all < hi) 
        else: 
            mask = (bmi_all >= lo) & (bmi_all <= hi) 
         
        if np.sum(mask) == 0: 
            purities.append(0.0) 
            dominant_clusters.append(-1) 
            continue 
             
        cluster_counts = np.bincount(labels[mask]) 
        purity = float(np.max(cluster_counts) / np.sum(cluster_counts)) 
        dominant_cluster = int(np.argmax(cluster_counts)) 
         
        purities.append(purity) 
        dominant_clusters.append(dominant_cluster) 
     
    overall_purity = float(np.mean(purities)) 
    return { 
        'purities': purities, 
        'dominant_clusters': dominant_clusters, 
        'overall_purity': overall_purity 
    }

    bmi_series: pd.Series, 
    labels: np.ndarray, 
    min_n: int = 30,

    bmi_data = pd.to_numeric(bmi_series, errors='coerce').astype(float).values

    if len(X) == 0: 
        raise RuntimeError('BMI 数据为空，无法进行 MDLP 离散化') 
     
    sorted_indices = np.argsort(X)

    y_sorted = y[sorted_indices] 
     
    def entropy(labels): 
         
        if len(labels) == 0: 
            return 0 
        _, counts = np.unique(labels, return_counts=True) 
        probs = counts / len(labels) 
        return -np.sum(probs * np.log2(probs + 1e-10)) 
     
    def mdl_criterion(left_labels, right_labels, total_labels): 
         
        n = len(total_labels) 
        n_left = len(left_labels) 
        n_right = len(right_labels) 
         
        if n_left == 0 or n_right == 0: 
            return float('inf') 
         
        total_entropy = entropy(total_labels) 
        weighted_entropy = (n_left/n) * entropy(left_labels) + (n_right/n) * 
entropy(right_labels) 
        info_gain = total_entropy - weighted_entropy 
         
        k = len(np.unique(total_labels))  # 类别数 
        description_length = (math.log2(n) + k * math.log2(n)) / n 
         
        return description_length - info_gain 
     
    def find_best_split(start_idx, end_idx, depth=0): 
         
        if end_idx - start_idx < 2 * min_n or depth >= math.log2(max_intervals): 
            return None

        segment_y = y_sorted[start_idx:end_idx]

            left_y = y_sorted[start_idx:i] 
            right_y = y_sorted[i:end_idx] 
            total_y = segment_y 
             
            mdl_score = mdl_criterion(left_y, right_y, total_y) 
             
            if mdl_score < best_mdl: 
                best_mdl = mdl_score 
                best_split = i 
         
        if best_split is not None and best_mdl < 0:   
            split_value = (X_sorted[best_split-1] + X_sorted[best_split]) / 2 
            return split_value, best_split 
         
        return None 
     
    def build_splits(start_idx, end_idx, depth=0):

        if result is None: 
            return []

def find_earliest_crossing(weeks: np.ndarray, probs: np.ndarray, p0: float) -> Optional[float]: 
    hit = probs >= p0 
    idx = np.where(hit)[0] 
    if idx.size == 0: 
        return None 
    i = int(idx[0]) 
    if i == 0: 
        return float(weeks[0]) 
    x0, x1 = float(weeks[i-1]), float(weeks[i]) 
    y0, y1 = float(probs[i-1]), float(probs[i]) 
    if y1 == y0: 
        return float(x1) 
    t = (p0 - y0) / (y1 - y0) 
    t = float(np.clip(t, 0.0, 1.0)) 
    return x0 + t * (x1 - x0)

def _penalty_norm_from_weeks(weeks: np.ndarray, penalty_type: str, k_exp: float = 0.25, 
pow_k: float = 2.0) -> np.ndarray: 
    weeks = weeks.astype(float) 
    late = np.maximum(0.0, weeks - 12.0) 
    if penalty_type == 'linear': 
        pen = late 
    elif penalty_type == 'poly': 
        pen = late ** float(pow_k) 
    elif penalty_type == 'exp': 
        pen = np.expm1(float(k_exp) * late) 
    else: 
        raise ValueError(f'未知的 penalty_type: {penalty_type}') 
    m = float(np.max(pen)) 
    if m <= 0: 
        return np.zeros_like(weeks, dtype=float) 
    return pen / m

def elbow_km_5(features: np.ndarray, k_min: int = 2, k_max: int = 8):

def _choose_thr_grp_25(y_true, y_prob, groups, group_names, target_metric='youden'): 
    thresholds = {} 
    for g in group_names: 
        mask = (groups == g) 
        y = y_true[mask] 
        p = y_prob[mask] 
        if len(y) == 0 or y.sum() == 0 or y.sum() == len(y): 
            thresholds[g] = 0.5 
            continue 
        cand = np.unique(np.clip(p, 0, 1)) 
        if cand.size > 200: 
            cand = np.quantile(cand, np.linspace(0, 1, 200)) 
        best_t, best_j = 0.5, -1 
        for t in cand: 
            pred = (p >= t).astype(int) 
            tp = int(((pred == 1) & (y == 1)).sum()) 
            fp = int(((pred == 1) & (y == 0)).sum()) 
            fn = int(((pred == 0) & (y == 1)).sum()) 
            tn = int(((pred == 0) & (y == 0)).sum()) 
            tpr = tp / (tp + fn) if (tp + fn) > 0 else 0.0 
            fpr = fp / (fp + tn) if (fp + tn) > 0 else 0.0 
            j = tpr - fpr 
            if j > best_j: 
                best_j, best_t = j, t 
        thresholds[g] = float(best_t) 
    return thresholds

def _choose_thr_spec_34(y_true: np.ndarray, y_prob: np.ndarray, target_spec: float) -> float: 
    if len(y_true) == 0: 
        return 0.5 
    cand = np.unique(np.clip(y_prob, 0, 1)) 
    cand = np.concatenate(([0.0], cand, [1.0])) 
    cand.sort() 
    best = 1.0 
    reached = False 
    for t in cand: 
        pred = (y_prob >= t).astype(int) 
        tn, fp, fn, tp = confusion_matrix(y_true, pred, labels=[0,1]).ravel() 
        spec = tn / (tn + fp) if (tn + fp) > 0 else 0.0 
        if spec >= target_spec: 
            best = t 
            reached = True 
            break 
    return best if reached else 1.0
